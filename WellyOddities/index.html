How indexing works
The initial 182 records are a date-stamped, manually checked snapshot. With the Python server running, “Refresh events” attempts to read public listings from the sources you've enabled. Glean, Engineering NZ, Fringe Bar, Humanitix, Eventfinda, Upper Hutt, National Library, Wellington City Libraries, Wellington Heritage Festival and Hutt City have dedicated readers; other websites use best-effort structured event data and HTML detection. Some sites hide data behind JavaScript, logins or anti-bot protections, so the app does not guarantee complete coverage. The status of each website is shown here; failed or unreadable sites are never counted as fully indexed. Live results replace that source's old snapshot only when dated events can actually be read.
Use the app with or without Python
Open this HTML file directly for the 13 October 2026 snapshot and all browsing filters. For live fetching, install Python 3, run START-WINDOWS.bat or START-MAC-LINUX.sh from the project folder, then open localhost:8765. No account is needed. Some third-party APIs require the organiser's own credentials, so this app uses publicly available event feeds where possible. Source exclusions, categories and saved events remain in your browser. Live crawling may be imperfect or blocked by individual sites; consult the linked organiser to check details and availability.
